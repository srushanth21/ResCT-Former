\begin{abstract}
Transformer-based approaches for remote sensing change detection (CD) have demonstrated strong performance due to their ability to model long-range dependencies. However, most existing methods rely heavily on large-scale pre-training, limiting their effectiveness on small CD datasets. In this work, we propose DSSAFormer-CD, a hybrid CNN-transformer framework designed for efficient training from scratch. The proposed model integrates a ResNet-34 backbone for stable spatial feature extraction and introduces a Deformable Shuffled Sparse Attention (DSSA) mechanism that dynamically reallocates sparse attention regions toward semantically informative areas. Additionally, a Change-Enhanced Feature Fusion (CEFF) module is employed to improve semantic interaction between bi-temporal features while suppressing noisy variations. Extensive experiments and ablation studies are conducted on benchmark datasets including LEVIR-CD, WHU-CD, and DSIFN-CD. Experimental results demonstrate that the proposed framework achieves strong performance while maintaining computational efficiency and stable convergence under training-from-scratch settings.
\end{abstract}

\section{Introduction}

Change detection (CD) in high-resolution optical remote sensing imagery aims to identify semantic differences between bi-temporal images acquired at different time instances. It is a critical technology for monitoring the Earth's dynamic surface and supports applications such as urban planning, agricultural monitoring, disaster assessment, and environmental analysis. Accurate CD methods are particularly important in scenarios involving illumination variations, seasonal changes, and complex urban structures.

Traditional deep learning approaches for CD primarily rely on Convolutional Neural Networks (CNNs), especially Siamese architectures, to extract and compare bi-temporal features. Although CNNs effectively capture local spatial information, their limited receptive field restricts the modeling of long-range contextual dependencies, which are important for distinguishing true semantic changes from pseudo-changes caused by shadows or environmental variations.

Transformer-based approaches address these limitations through self-attention mechanisms capable of modeling global context. Methods such as BIT and ChangeFormer demonstrate strong performance by capturing long-range dependencies. However, these approaches typically depend on large-scale pre-training to learn effective inductive biases, limiting their applicability in remote sensing scenarios where annotated data is limited.

Recent approaches such as ScratchFormer demonstrated that transformers can be trained from scratch using sparse attention mechanisms that focus on informative regions instead of dense global attention. Nevertheless, existing sparse attention approaches generally rely on fixed sparsity patterns, which are suboptimal for heterogeneous remote sensing scenes containing varying object scales and spatial complexities.

To address these limitations, we propose \textbf{DSSAFormer-CD}, a hybrid CNN-transformer framework designed for efficient training from scratch. The proposed framework integrates a ResNet-34 backbone for stable spatial feature extraction and introduces a \textit{Deformable Shuffled Sparse Attention (DSSA)} mechanism that adaptively reallocates sparse attention regions toward semantically informative areas. Furthermore, a CEFF module is employed to improve semantic interaction between bi-temporal features.

We evaluate the proposed framework on benchmark datasets including LEVIR-CD, WHU-CD, and DSIFN-CD using extensive quantitative and ablation experiments.

The main contributions of this work are summarized as follows:

\begin{itemize}

\item We propose DSSAFormer-CD, a hybrid CNN-transformer framework designed for remote sensing change detection training entirely from scratch.

\item We introduce Deformable Shuffled Sparse Attention (DSSA), which dynamically reallocates sparse attention regions using learnable spatial offsets.

\item We integrate a ResNet-34 backbone with CEFF-based semantic fusion to improve feature representation and training stability in low-data regimes.

\item We design extensive experiments and ablation studies across LEVIR-CD, WHU-CD, and DSIFN-CD datasets to evaluate the effectiveness of deformable sparse attention.

\end{itemize}

\section{Related Work}

\subsection{CNN-Based Change Detection}

Early deep learning approaches for remote sensing change detection predominantly relied on Convolutional Neural Networks (CNNs). Siamese architectures with shared weights have been widely adopted to extract feature representations from bi-temporal images \cite{placeholder_siam}. FCN and UNet-based variants such as FC-Siam-conc and FC-Siam-diff \cite{placeholder_fcsiam} generate high-resolution change maps using dense skip connections. While effective at capturing local spatial structures, CNNs struggle to model long-range contextual dependencies due to the locality of convolution operations.

\subsection{Transformer-Based Change Detection}

Vision Transformers (ViTs) \cite{placeholder_vit} introduced self-attention mechanisms capable of modeling global dependencies across image regions. Methods such as BIT \cite{placeholder_bit} and ChangeFormer \cite{changeformer} significantly improved CD performance by integrating transformer-based attention into Siamese frameworks. However, transformers typically require large-scale pre-training to achieve convergence due to their weak inductive biases.

\subsection{Training Change Detection Models from Scratch}

ScratchFormer \cite{scratchformer} demonstrated that transformers can be trained from scratch for CD tasks by introducing sparse attention mechanisms. By restricting attention computations to informative regions, sparse attention reduces computational complexity and overfitting. However, existing methods employ fixed sparse sampling patterns that cannot adapt to varying spatial structures in remote sensing imagery.

The objective of DSSAFormer-CD is to predict a binary change mask
$M \in \{0,1\}^{H \times W}$ given a pair of co-registered images
$I_{pre}, I_{post} \in \mathbb{R}^{3 \times H \times W}$.

\subsection{Hybrid ResNet-34 Backbone}

Instead of relying solely on transformer encoders, DSSAFormer-CD utilizes a ResNet-34 backbone to extract hierarchical spatial features. CNN-based feature extraction provides stable low-level structural representations that facilitate convergence in low-data training scenarios.

The extracted feature maps at stage $i$ are represented as:

\begin{equation}
F_{pre}^{i}, F_{post}^{i}
\in
\mathbb{R}^{C \times \frac{H}{S} \times \frac{W}{S}}
\end{equation}

where $S$ denotes the stride factor.

\subsection{Deformable Shuffled Sparse Attention (DSSA)}

Standard dense self-attention exhibits quadratic computational complexity with respect to the number of tokens. DSSA performs sparse token interactions over adaptively shifted spatial regions.

Unlike fixed sparse attention, DSSA introduces learnable spatial offsets that dynamically shift sparse sampling locations toward semantically informative regions.

First, deformable offsets are computed using a lightweight convolutional module:

\begin{equation}
\Delta z = (\Delta x, \Delta y) = \theta_{offset}(F^i)
\end{equation}

Sparse sampled features are then obtained as:

\begin{equation}
\bar{F}_{k,l}^{i}(\bar{x},\bar{y})
=
F^{i}
(
\gamma \bar{x} + k + \Delta x,
\gamma \bar{y} + l + \Delta y
)
\end{equation}

where $k,l \in \{0,\dots,\gamma-1\}$.

The sampled features are projected into Query, Key, and Value matrices:

\begin{equation}
Q = \bar{F}^{i}W_Q,
\quad
K = \bar{F}^{i}W_K,
\quad
V = \bar{F}^{i}W_V
\end{equation}

Self-attention is computed as:

\begin{equation}
\text{Attention}(Q,K,V)
=
\text{softmax}
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
\end{equation}

The attended sparse features are reshuffled back to their original spatial arrangement to obtain refined feature maps $\hat{F}^{i}$.

\subsection{Change-Enhanced Feature Fusion (CEFF)}

The CEFF module enhances semantic interaction between bi-temporal features while suppressing noisy variations.

A global context vector is computed using Global Average Pooling (GAP):

\begin{equation}
p^i = \text{GAP}(\hat{F}_{pre}^{i} + \hat{F}_{post}^{i})
\end{equation}

Channel-wise weights are generated using shared MLP layers followed by softmax normalization:

\begin{equation}
F_{enh}^{i}
=
v_{pre}^{i}\odot\hat{F}_{pre}^{i}
+
v_{post}^{i}\odot\hat{F}_{post}^{i}
\end{equation}

where $\odot$ denotes element-wise multiplication.

\subsection{Loss Function}

The fused features are passed through the decoder to generate the probability map
$P \in \mathbb{R}^{H \times W}$.

To optimize the network, we employ a hybrid loss function combining BCE loss and Dice loss:

\begin{equation}
\mathcal{L}_{total}
=
\mathcal{L}_{BCE}
+
\lambda \mathcal{L}_{Dice}
\end{equation}

The BCE loss is defined as:

\begin{equation}
\begin{split}
\mathcal{L}_{BCE}
=
-\frac{1}{H \times W}
\sum_{x,y}
[
Y_{x,y}\log(P_{x,y})
+
(1-Y_{x,y})\log(1-P_{x,y})
]
\end{split}
\end{equation}

The Dice loss is formulated as:

\begin{equation}
\mathcal{L}_{Dice}
=
1
-
\frac{
2\sum_{x,y}P_{x,y}Y_{x,y}+\epsilon
}{
\sum_{x,y}P_{x,y}
+
\sum_{x,y}Y_{x,y}
+
\epsilon
}
\end{equation}

where $\epsilon$ is a small constant for numerical stability.

\subsection{Computational Complexity Analysis}

Dense self-attention requires $\mathcal{O}(N^2)$ operations due to pairwise token interactions over all spatial locations.

In contrast, DSSA performs attention only over sparse sampled regions, reducing complexity to:

\begin{equation}
\mathcal{O}
\left(
\frac{N^2}{\gamma^2}
\right)
\end{equation}

where $\gamma$ denotes the sparse sampling factor.

The deformable sparse sampling strategy improves computational efficiency while preserving semantically important spatial structures.

\begin{algorithm}[htbp]
\caption{Inference of DSSAFormer-CD}
\label{alg:inference}
\begin{algorithmic}[1]

\REQUIRE Co-registered images $I_{pre}, I_{post}$

\ENSURE Binary change map $M$

\STATE Extract hierarchical features using Siamese ResNet-34

\STATE $F_{pre}^{1\dots4},F_{post}^{1\dots4}
\leftarrow
\text{ResNet}(I_{pre}),\text{ResNet}(I_{post})$

\FOR{$i=1$ to $4$}

\STATE Compute deformable offsets $\Delta z$

\STATE Extract sparse sampled subsets

\STATE Compute sparse self-attention

\STATE Reshuffle attended features

\STATE Fuse features using CEFF

\ENDFOR

\STATE Concatenate multiscale features

\STATE Decode final probability map $P$

\STATE Generate binary mask $M$

\RETURN $M$

\end{algorithmic}
\end{algorithm}

\section{Experimental Setup}

\subsection{Datasets}

We evaluate DSSAFormer-CD on three benchmark datasets:

\textbf{LEVIR-CD:}
637 image pairs with resolution $1024 \times 1024$ cropped into $256 \times 256$ patches.

\textbf{WHU-CD:}
A large-scale aerial building change detection dataset using $512 \times 512$ cropped patches.

\textbf{DSIFN-CD:}
A multi-temporal dataset containing seasonal and illumination variations.

\subsection{Implementation Details}

The model is implemented in PyTorch and trained entirely from scratch.

We use the AdamW optimizer with:
\begin{itemize}
\item Initial learning rate: $1\times10^{-4}$
\item Weight decay: $0.01$
\item Batch size: $16$
\end{itemize}

Data augmentation includes:
\begin{itemize}
\item Random flipping
\item Random rotation
\item Gaussian blur
\end{itemize}

Models are trained for 200 epochs using a cosine annealing learning rate scheduler. All experiments are conducted on NVIDIA RTX-series GPUs.

\subsection{Evaluation Metrics}

We evaluate performance using:
\begin{itemize}
\item Intersection over Union (IoU)
\item F1-score
\item Overall Accuracy (OA)
\end{itemize}

\section{Conclusion}

This work presented DSSAFormer-CD, a hybrid CNN-transformer framework for remote sensing change detection trained entirely from scratch. The proposed Deformable Shuffled Sparse Attention (DSSA) mechanism dynamically reallocates sparse attention regions toward semantically informative spatial locations while reducing computational redundancy. Combined with a ResNet-34 backbone and CEFF-based semantic fusion, the proposed framework is designed to improve feature representation and training stability in low-data remote sensing scenarios. Extensive experiments and ablation studies on benchmark datasets will further validate the effectiveness of the proposed framework in terms of both accuracy and computational efficiency.
